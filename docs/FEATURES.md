# FEATURES — INNOCEAN Benchmark

## 페이지 구성

1. **벤치마크 조회** — 업종별 광고 KPI 벤치마크 검색 + 필터.
   - 비교 기준 토글: **업종** / **업종 × 광고상품**(층화). 층화는 칸이 곱으로 늘어
     광고비 상위 40칸만 보여주고 몇 칸을 뺐는지 적는다.
   - 표본 하한 20, 중앙값 신뢰구간, 기간 비교(전기·전년), 분포폭 경고,
     커버리지 게이트(분자가 빠진 지표는 0 이 아니라 «견줄 수 없음»).
2. **AI 분석 채팅** — 자연어로 질문 → 벤치마크 데이터 기반 응답.
3. **소재 벤치마크(디플랜 NAS)** — 소재 단위 19컬럼 나열 + 합계·평균,
   초성 검색·오탈자 1자 허용, **행/열 교차표**(칸 값은 합계에서 다시 계산).
   ⚠️ API 수집 매체와 합산 금지 — 같은 캠페인이 양쪽에 있어 이중계상된다.
4. **도달 시뮬레이터** — 예산 대비 도달. 제공자 5종을 같은 축에 나란히 놓고
   곡선마다 «무엇을 재는가» 를 표로 적는다.

## 도달 제공자 (reach.py)

| 제공자 | 성격 | 재는 것 | 상태 |
|---|---|---|---|
| 가정 기반 추정 | 가정식 | 한 모집단이 포화되는 모양 | 동작 |
| 실측 적합 | 우리 실측 | **캠페인 사이** — 예산 규모가 다른 캠페인을 가로질러 본 관계 | 동작 |
| Netflix Reach Curve | 벤더 예측 | **한 조건 안** — 같은 타게팅에서 노출을 늘렸을 때 | 토큰 주입 대기 |
| Google ReachPlanService | 벤더 예측 | 같음(YouTube·디스플레이) | 개발자 토큰 미발급 |
| Meta Reach & Frequency | 벤더 예측 | 같음 | ads_management 권한 필요 |

규칙:
- 게이트는 «테이블 존재» 가 아니라 **«쓸 수 있는 곡선이 있나»**. 빈 스키마가 먼저
  생겨도 화면이 곡선 0개로 열리지 않는다.
- 벤더 API 는 호출 한도가 있어 **요청 경로에서 부르지 않는다** — 야간 격자 선계산 →
  BQ 캐시 → 화면은 캐시만 조회.
- 집행기간 버킷 안에서 적합한다(기간을 섞으면 기간 효과가 수확체감으로 보인다).
  **120일 초과는 답하지 않는다** — 온전한 표본 2건.
- 도달률(%)의 분모는 **캐시 행에서** 읽고 **범위로** 그린다. `population_source` 로
  벤더 제공(`vendor_api`)과 가정(`assumed`)을 구분한다.
- 구글·DV360 이 실측 적합에 없는 이유는 «수집을 안 해서» 가 아니다 — CM360 노출
  로그(93.1M행)는 있는데 `User_ID` 가 전부 비어 있어 유니크 도달을 셀 수 없다.
3. **Summary 차트** — 업종별 / 매체별 KPI 분포 시각화.

## 1. 벤치마크 조회

### 필터

- **업종**: 자동차 / 금융 / 화장품 / F&B / 전자 / 패션 등.
- **매체**: Google / Meta / 네이버 / 카카오 / YouTube / 인스타.
- **기간**: 2024 / 2025 / 2026 (분기 단위).
- **KPI**: CPM / CPC / CTR / VTR / CVR / ROAS.

### 결과 표시

- 표 형식 (업종 × 매체 × KPI).
- 평균 / 중앙값 / 상위 25% / 상위 10% 4분위 표시.
- 캠페인 비교 가능.

---

## 2. AI 분석 채팅

### 입력 패턴 (rule-based)

| 의도 | 키워드 | 동작 |
|---|---|---|
| 업종 조회 | "[업종] 평균 / 벤치마크" | 해당 업종 KPI 평균 + 중앙값 응답 |
| 매체 비교 | "[매체A] vs [매체B]" | 두 매체 KPI 비교 차트 + 텍스트 |
| 이상치 탐지 | "이상치 / 특이값" | 평균 대비 ±2σ 벗어난 케이스 |
| 트렌드 | "분기별 / 추이" | 시계열 차트 응답 |
